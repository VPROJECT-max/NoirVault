# NoirVault Keyboard Shortcuts

NoirVault is designed to be operated almost entirely from the keyboard to ensure maximum speed and efficiency.

## Global Shortcuts
These shortcuts work anywhere within the unlocked vault interface:

- **`Ctrl + K`** : Instantly focus the Search Bar.
- **`Up Arrow`** : Move the selection cursor up the list.
- **`Down Arrow`** : Move the selection cursor down the list.
- **`Enter`** : Instantly copy the password of the currently selected item to your clipboard (triggers the 15-second secure wipe sequence).

*Note: More shortcuts will be added as the project evolves.*
